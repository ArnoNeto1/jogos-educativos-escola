Pillage First! (Ask Questions Later)

Pillage First! (Ask Questions Later) is an open-source, single-player, strategy game inspired by Travian.

Build villages, manage resources, train troops, start adventures and wage war in persistent, offline-first game worlds.

Pillage First! requires no account or download. We strive to offer a more customizable and time-friendly alternative to Travian.

Motivation behind Pillage First!

I've always been a huge fan of Travian and similar browser-based strategy games. The slow, methodical village-building, resource management, and real-time progression made those games incredibly special.


Sadly, Travian requires a massive time (and gold!) investment to remain competitive. Not being able to commit either of these, I set out to create a similar, but less commitment-hungry experience, with more quality-of-life features and customizability to make your experience better!


Pillage First! is my attempt to recreate that experience as a single-player Travian alternative, with the same core mechanics, but modernized, offline-friendly, and fully open source, with no game mechanics to incentivize spending real-world money. Just the classic gameplay loop, reimagined for solo play.


Whether you're looking for a Travian offline experience or a Travian single player adventure, Pillage First! aims to provide that classic strategy feel without the pressure of 24/7 competition. As a Travian open source project, it's built by the community, for the community.

Frequently asked questions

Short answers for the things people usually want to know before starting a world.

Are there game design differences between Travian and Pillage First!?

+

Yes, there are a few! The main ones include new buildings, the removal of the capital village mechanic, expanded artifact system, planned new hero items and more NPC interactions. Mechanics are always up for discussion, so make sure to join our Discord server and share with us your thoughts!

Can I create more than one game world at a time?

+

Yes! You may create as many game worlds as you wish. You may also duplicate or export and share your game worlds with other players.

Why single player?

+

We want to provide each player with the ability to customize their own unique gameplay experience. This is not possible in a multiplayer environment.

Does the game continue even if I close the app?

+

Yes! You're free to close the app at any time and the game will pick off right next time you open it again! Units will continue to be trained, buildings will continue to be constructed and troops will continue to raid exactly as they would if you kept the app running.

Can game worlds be shared between devices?

+

Yes! You can do so by either manually exporting and re-importing game world file, or by using an automatic method, which is only possible to do with devices on the same network.
