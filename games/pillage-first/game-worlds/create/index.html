Create a new game world

Creating a new game world will generate a game state and store it in your browser's persistent memory. You can safely close the tab or browser at any time, your server will still be there when you return. A link to your new server will appear in the server list on the homepage, and you'll be automatically redirected to it after creation.

The game is still in development, game worlds may become incompatible between updates. This means worlds will sometimes need to be deleted and recreated. Please use the app for testing purposes only until the full release.
